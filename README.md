## Usage

To run this project, install o Jekyll globaly:
> for more information on jekyll installation go to the [official documentation](https://jekyllrb.com/docs/installation/)

```shell
$ gem install bundler jekyll
```

#### Install project dependencies

```shell
$ make install
```

#### Serve the project

```shell
$ make serve
```

#### Build with `mathauden.github.io` url

```shell
$ make build
```

#### Build with `mathauden.com` url

```shell
$ make build-dotcom
```
